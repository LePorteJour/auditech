Collez le code reçu par mail, WhatsApp ou SMS :
💡 Sur l'autre appareil, vous avez choisi « Envoyer ». Ouvrez le mail ou le message reçu, sélectionnez tout le code (de AT2| jusqu'à la fin), copiez-le, puis collez-le ci-dessus.
📥 Importer une session
Importez un fichier de session exporté depuis AuditTech pour continuer votre travail sur cet appareil.
📂
Cliquer ou glisser-déposer le fichier
Fichier .json exporté depuis AuditTech
ℹ️ L'import remplacera les données actuelles sur cet appareil. Pensez à exporter votre session avant si vous avez des données à conserver.
🔀 Fusionner une session
Importez le fichier JSON d'un collègue. Ses données seront ajoutées aux vôtres sans rien écraser.
🔀
Cliquer ou glisser-déposer le fichier JSON
Fichier .json exporté par votre collègue
📋 Aperçu de la fusion :
ℹ️ La fusion complète vos données : les champs vides chez vous seront remplis par ceux du collègue. Les observations des deux auditeurs sont concaténées. Aucune donnée existante n'est supprimée.
